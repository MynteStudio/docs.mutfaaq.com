title: Download & print
description: Choose and download the QR codes you want to print.
---

Mutfaaq provides two types of QR codes:

- the **generic venue QR code**, which opens the public menu without a table;
- a **table QR code**, which opens the menu through one specific table.

## Choose the correct QR code

Use the generic QR code for a storefront, flyer, website, takeaway packaging, or any support that is not assigned to a table.

Use table QR codes on tables. Each printed code remains connected to the table for which it was created.

## Download a file

From **Settings** > **Links & QR codes**:

- select **Download QR code** beside the generic link or an individual table;
- select **Download all QR codes** to retrieve all table codes together;
- choose **Download SVG** or **Download PDF**.

| Format | Use it when |
| --- | --- |
| **SVG** | You need a scalable file for a designer or professional printing workflow. |
| **PDF** | You want a document that can be opened and printed directly. |

<Warning>
  Test the printed QR code with a phone before producing multiple copies. Do not reuse a table QR code after deleting its table, because its link no longer works.
</Warning>
