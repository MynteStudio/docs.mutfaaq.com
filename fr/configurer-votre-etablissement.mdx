---
title: Configurer votre établissement
description: Ajoutez votre établissement et choisissez les paramètres utilisés par vos menus.
---

Lors de votre première connexion à Mutfaaq, vous devez créer votre établissement avant de créer un menu.

<Steps>
  <Step title="Trouver votre établissement">
    Recherchez votre établissement par son nom ou son adresse. Sélectionnez le bon résultat pour récupérer ses informations publiques depuis Google.

    Si vous ne le trouvez pas, sélectionnez **Vous ne trouvez pas votre établissement ? Saisissez les informations manuellement**.
  </Step>
  <Step title="Vérifier les informations">
    Vérifiez le **Nom de l’établissement**, l’**Adresse** et le **Pays**. Vous pouvez également ajouter une courte description maintenant ou la compléter plus tard.
  </Step>
  <Step title="Choisir le fuseau horaire">
    Sélectionnez le fuseau horaire où se trouve l’établissement. Mutfaaq l’utilise pour programmer les disponibilités et les promotions.
  </Step>
  <Step title="Choisir la devise">
    Sélectionnez la devise utilisée pour les prix des menus de cet établissement.
  </Step>
  <Step title="Choisir la langue de l’établissement">
    Sélectionnez la langue dans laquelle vous rédigerez le contenu original du menu et la description de l’établissement. Mutfaaq utilise ce contenu comme source pour les traductions automatiques.
  </Step>
  <Step title="Terminer la création">
    Vérifiez les informations, puis sélectionnez **Terminer la configuration**.
  </Step>
  <Step title="Choisir trois langues prioritaires">
    Sélectionnez trois langues parmi celles que vos clients utilisent le plus. Pendant l’essai, ces trois traductions et votre langue source sont disponibles sur le menu public.

    Sélectionnez **Terminer la configuration** pour ouvrir votre tableau de bord.
  </Step>
</Steps>

<Warning>
  Vérifiez attentivement le **Pays**, le **Fuseau horaire**, la **Devise** et la **Langue de l’établissement**. Ces paramètres ne sont plus modifiables après la création de l’établissement.
</Warning>

## Bien choisir vos paramètres

- Choisissez le fuseau horaire de l’établissement, même si vous le gérez depuis un autre pays.
- Choisissez la devise dans laquelle vous saisissez et affichez les prix du menu.
- Choisissez la langue dans laquelle votre équipe rédigera les noms et descriptions d’origine.
- Choisissez les trois langues de traduction les plus utiles à vos clients actuels.
