---
title: Télécharger et imprimer
description: Choisissez et téléchargez les codes QR que vous souhaitez imprimer.
---

Mutfaaq propose deux types de codes QR :

- le **code QR général de l’établissement**, qui ouvre le menu public sans table ;
- un **code QR de table**, qui ouvre le menu depuis une table précise.

## Choisir le bon code QR

Utilisez le code QR général sur une vitrine, un flyer, un site internet, un emballage à emporter ou tout support qui n’est pas associé à une table.

Utilisez les codes QR de table sur les tables. Chaque code imprimé reste associé à la table pour laquelle il a été créé.

## Télécharger un fichier

Depuis **Paramètres** > **Liens et codes QR** :

- sélectionnez **Télécharger le code QR** à côté du lien général ou d’une table ;
- sélectionnez **Télécharger tous les codes QR** pour récupérer ensemble les codes de toutes les tables ;
- choisissez **Télécharger en SVG** ou **Télécharger en PDF**.

| Format | Utilisez-le lorsque |
| --- | --- |
| **SVG** | Vous avez besoin d’un fichier redimensionnable pour un graphiste ou une impression professionnelle. |
| **PDF** | Vous souhaitez ouvrir et imprimer directement un document. |

<Warning>
  Testez le code QR imprimé avec un téléphone avant de produire plusieurs exemplaires. Ne réutilisez pas le code QR d’une table supprimée, car son lien ne fonctionne plus.
</Warning>
